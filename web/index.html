FAQ

常见问题

API Key 会泄露吗？

不会。Key 仅保存在当前浏览器会话内存中，请求直接由你的浏览器发往模型商，不经第三方服务器中转。

生成的文件能再编辑吗？

能。输出是标准的 .pptx 文件，所有形状、图表、备注、动画均为原生对象，可在 PowerPoint / Keynote / WPS 中继续编辑。

没有模型 API Key 能用吗？

可以。使用「离线体验 Demo」即可用内置示例大纲完整生成一份演示文稿；也可以准备一份大纲 JSON 直接渲染。

如何在自己的服务器上部署？

安装依赖后执行 uvicorn slideforge.api:app --host 0.0.0.0 --port 8000 即可，或使用仓库内的 Dockerfile。
